# Every macro, enumerator, typedef and host import that plugins/sdk/netvis_plugin.h
# exposes, one per line, sorted. tests/test_plugin_abi_freeze.cpp re-derives this
# list from the header on every run and fails if the two disagree.
#
# This file is the freeze. A shipped plugin binds to these names and values at
# compile time, so changing one is not a refactor — it is an ABI break, and it
# has to be an explicit, reviewable edit here rather than a side effect of
# editing the header. See docs/plugin-abi.md ("Compatibility promise") for what
# may change within ABI v1 and what forces a version bump.
#
# Lines are `<kind> <name>[ = <value>]`, where kind is one of:
#   define  a preprocessor macro; `NAME()` marks a function-like macro, whose
#           body is not frozen (it expands to toolchain attributes)
#   enum    an enumerator of nv_dtype_t or nv_category_t, with its exact value
#   import  a host function a guest module may import, as `<module> <name>`
#   type    a typedef name (nv_tensor_hdr_t's layout is _Static_assert'ed in the
#           header itself, so only its existence is frozen here)
