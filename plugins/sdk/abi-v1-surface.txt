# Everything a plugin binds to, one entry per line: the macros, enumerators, typedefs,
# struct members and guest helpers plugins/sdk/netvis_plugin.h exposes; every host
# import WITH ITS WASM SIGNATURE; and every guest export the host calls by name.
# tests/test_plugin_abi_freeze.cpp re-derives all of it on every run - the header from
# netvis_plugin.h, the exports and the host side of the imports from the host's own
# link tables and call sites - and fails if any of it disagrees with this file.
#
# This file is the freeze. A shipped plugin binds to these names, numbers and
# signatures at compile time, so changing one is not a refactor — it is an ABI break,
# and it has to be an explicit, reviewable edit here rather than a side effect of
# editing the header or the host. See docs/plugin-abi.md ("Compatibility promise") for
# what may change within ABI v1 and what forces a version bump.
#
# Lines are `<kind> ...`, where kind is one of:
#   define  a preprocessor macro, `NAME = value`; `NAME()` marks a function-like macro,
#           whose body is not frozen (it expands to toolchain attributes)
#   type    a typedef: `type <name> = <underlying type>`, or `= enum` / `= struct` for a
#           block typedef (the block's contents are the enum / field lines)
#   enum    an enumerator of a typedef'd enum, with its exact explicit decimal value
#   field   a wire-struct member: `field <struct> <index> <type> <name>`. The index is
#           the declaration order, so reordering members is a change even when the size
#           is not (tests/test_sdk_abi.cpp additionally asserts the offsets)
#   helper  a guest-side function the header defines (the bump allocator)
#   import  a host function a guest may import:
#             import <facet> <module> <name> <wasm signature> as <C prototype name>
#           The facet (op, parser, pass) is the part of the ABI whose adapter links it:
#           the parser and the pass both use module "netvis" with DISJOINT imports, so
#           an import is only available in the facet that links it. The signature is
#           what the guest must declare and the host must link (wasm notation); wasm3
#           refuses a link whose signature differs, so a mismatch is not "slightly
#           off", it is an import that never binds.
#   export  a function the host looks up in a guest module by name, in the facet that
#           calls it. Every entry point is `() -> i32` (WasmModule::call_i32 refuses
#           any other shape). Whether an export is required is a policy, not a name:
#           see docs/plugin-abi.md ("How a mismatch is refused").
